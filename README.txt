Alice 個人介紹網站
====================

檔案：
- index.html：完整網站，CSS 與 JavaScript 已內嵌，不需要額外素材。

本機預覽：
1. 將 ZIP 解壓縮。
2. 開啟 index.html，即可用瀏覽器預覽。

上傳網站：
1. 將 index.html 上傳到你的靜態網站主機或網站空間。
2. 若主機要求首頁檔名，請保留 index.html。
3. 若使用 GitHub Pages、Netlify、Cloudflare Pages 等服務，可將解壓後的網站資料夾部署。

注意：
- 作品集目前是文字介紹卡片，並非實際作品圖片。
- Email 已設定為 mailto 連結。
- 若要公開網站，請確認是否希望公開顯示電子郵件地址。
